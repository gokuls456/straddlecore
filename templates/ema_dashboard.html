Connect to Dhan

Paste your Dhan access token. Create one at web.dhan.co, then Profile, then Access DhanHQ APIs. A token works for 24 hours, so you paste a new one each day.

The token stays in this browser and is sent only to this dashboard's server, which uses it to read market data from Dhan. It is never saved on the server and this page cannot place orders.
